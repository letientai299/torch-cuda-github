# Security

This is a throwaway sandbox repository used to rehearse a repository sync
workflow. It is not a supported package, it is not published to any index, and
nothing here should be depended on.

The file exists so the publish pipeline has a `SECURITY.md` to carry, and so the
GitHub "security policy" surface is exercised.

## Reporting

If you find something anyway, open a private report through
[GitHub's private vulnerability reporting][ghsa] on this repository rather than
a public issue.

[ghsa]: https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability
